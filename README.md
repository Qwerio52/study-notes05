# study-notes05

#### \# 第6章 组合数据类型 学习心得

本章学习了Python四种组合数据类型：\*\*集合、列表、元组、字典\*\*，同时学习了序列的通用操作、词频统计思路以及jieba中文分词库的基础使用。



\## 知识点梳理

1\. \*\*集合 set\*\*：元素无序、唯一，自动去重。适合求交集、并集、差集，用来做去重、判断成员关系，但是集合不支持下标索引，不能保存重复数据。

2\. \*\*列表 list\*\*：有序可变序列，是最常用的容器。支持增删改查，索引、切片；适合存储有序、需要随时修改的数据。缺点是查找效率低，大量数据查找时性能不如字典。

3\. \*\*元组 tuple\*\*：有序不可变序列，一旦创建不能修改元素。可以作为字典的key，适合存放不希望被修改的数据，起到数据保护的作用。

4\. \*\*字典 dict\*\*：键值对（key-value）映射结构，key唯一、无序（Python3.7后保留插入顺序），查找速度快。非常适合做统计、映射关系，比如词频统计。



\## 学习收获

1\. 分清可变与不可变类型是本章重点：列表、集合可变；元组、字符串不可变。这个特性决定了它们各自适合的场景。

2\. 序列通用操作：列表、元组、字符串都属于序列，都支持切片、索引、`in`、`len()`等操作，学习的时候可以归类记忆。

3\. 词频统计是很经典的字典场景：遍历文本单词，用单词作为key，出现次数作为value，不断累加计数。书中《哈姆雷特》英文词频、《三国演义》人物出场统计，都是同一个核心思路。

4\. jieba分词：英文天然按空格分割，中文句子没有分隔符，需要第三方分词库拆分词语，才能做中文词频统计，拓展了文本处理能力。

5\. 选型思维：现在知道面对需求时先选容器：

&#x20;   - 需要去重、集合运算 → 集合

&#x20;   - 有序、经常增删 → 列表

&#x20;   - 有序、数据固定不修改 → 元组

&#x20;   - 需要一对一查找、统计计数 → 字典



\## 存在不足

1\. 对集合各种运算符（`\& | - ^`）容易记混，需要多敲代码巩固。

2\. 字典的高级方法（`get()`、`items()`、`defaultdict`）还不够熟练，词频统计写法还可以进一步简化。

3\. jieba分词还有精确模式、全模式、搜索引擎模式，本章只简单了解，后续可以尝试不同分词模式对比效果。

4\. 还需要多练习容器嵌套（列表套字典、字典套列表），这是后续处理复杂数据的基础。



\## 小结

组合数据类型是Python存放批量数据的核心工具。本章不再只是处理单个变量，而是学会批量管理一组数据，为后续爬虫、数据分析、文本处理打下基础。不同容器各有取舍，没有最好的类型，只有最合适的类型。
